# Image Generation Prompts

The four project renders were generated with the built-in image-generation tool.
These are the final prompt specifications, preserved for provenance and future
design iteration.

## Complete system

```text
Use case: stylized-concept
Asset type: surgical robotics project hero render
Primary request: complete modular surgeon-controlled robotic surgery system in a modern empty operating-room training lab
Subject: surgeon console, medical compute cart, four independent compact bedside carts, one stereo camera arm, three instrument arms, empty table
Style: highly realistic industrial-design / CAD product render, wide 16:9
Palette: matte white and gray, graphite joints, restrained cyan status accents
Constraints: no people, patient, anatomy, blood, surgical action, logos, text, or watermark; physically plausible; arms do not touch the empty table
```
